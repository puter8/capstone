# 5축 신뢰도 — 구현 근거와 평가 범위를 구분한 정리

2026-10-14. 세션 종료 후 캐릭터 변화를 공개하는 정책은 유지한다. 아래는 향후 시각 매핑의 참고 자료이며 디자인 변경안은 아니다.

## 잠정 순서

**구현 재현성·사람 참조 근거·구간별 평가 범위를 함께 고려하면 친밀도 → 호기심 → 격식 → 유머 → 에너지 순으로 보수적으로 다루는 것이 합리적이다.** 이는 공통 척도로 산출한 통계적 순위가 아니라 현재 확보된 근거를 바탕으로 한 판단이다. 서로 다른 정의와 지표를 정확도 백분율 하나로 바꾸지 않는다.

| 순서 | 축 | 확인된 근거 | 사용할 때의 한계 |
|---|---|---|---|
| 1 | Intimacy 친밀도 | 세션 수를 `100×n/(n+10)`으로 계산하는 결정적 공식. 같은 입력이면 같은 결과 | 심리적 친밀감의 정확도를 측정한 것은 아님. 현재 남아 있는 세션 행 수여서 기록 삭제 시 줄 수 있음 |
| 2 | Curiosity 호기심 | 사람 4인 점수 ICC(1,k) 0.835. 채택 모델 개발 평가 MAE 10.83점, 유효 30문장. 낮음 23/24, 중간 5/6 구분 | 높은 구간 평가 문장 0개. 사람 참조보다 평균 6.83점 높게 예측. 전체 구간 일반화는 미확인 |
| 3 | Formality 격식 | ICC(1,k) 0.474. 개발 평가 MAE 10.17점, 30문장. 낮음 3/8, 중간 15/17, 높음 5/5 구분 | 사람 간 합의가 상대적으로 낮고 낮은 격식 구간 구분이 약함. 높은 구간 5개는 소수 표본 |
| 4 | Humor 유머 | ICC(1,k) 0.686. 개발 평가 MAE 4.00점, 35문장. 현재 낮은 유머 중심 분포에서 오차가 작음 | 낮음 34개, 중간 1개, 높음 0개. 중간 1개도 낮음으로 예측. 낮은 점수 자체가 오류는 아니지만 중·고 유머 대응 능력을 확인할 자료가 부족 |
| 5 | Energy 에너지 | 같은 사람 녹음 10개 전부 측정 성공, 첨부 수치 재현. 보정 후 억양 폭 중앙값 4.48반음·표준편차 1.50반음. 재조합 시뮬레이션 중간 87.9% | 개인 평소 억양 폭 대비 변화 신호. 사람의 활력 판단과 일치율, 의도적으로 달리 말했을 때 민감도, 여러 사용자·환경의 일반화 미검증. 87.9%는 정확도가 아님 |

친밀도는 계산의 확실성이 높다는 뜻이지 모델보다 인간 심리를 더 정확하게 측정한다는 뜻이 아니다. 에너지도 측정값을 재현할 수 있지만 ‘활기찬 정도’를 잘 구별한다는 결론은 별도 검증이 필요하다. 호기심과 격식의 우선순위는 사용할 점수 구간에 따라 달라질 수 있다.

## 세 가지 순위를 혼동하지 않기

- **채택 모델의 현재 개발 평가 MAE:** 유머 4.00 < 격식 10.17 < 호기심 10.83. 작은 값이 해당 평가 분포에서 참조 점수와 가깝다는 뜻이다.
- **과거 4인 평가 점수 일관성 ICC(1,k):** 호기심 0.835 > 유머 0.686 > 격식 0.474. 이는 모델 성능이 아니라 사람 채점의 일관성이다.
- **전체 제품에서 다룰 근거의 충분함:** 위 표의 잠정 순서. 높은 유머나 높은 호기심의 근거 부족은 평균 오차만으로 해결되지 않는다.

3축 평가 문장 총 35개는 모델 선택에도 사용한 개발 자료다. 따라서 MAE를 손대지 않은 최종 시험 성능으로 발표하지 않는다. 보호된 31개에는 사람 점수가 없어 독립 최종 정확도 수치를 산출하지 않았다. 사용자가 정한 시제품 채택 기준(각 축 MAE 13점 이하)은 개발 평가에서 충족했다는 범위로 설명한다.

## 에너지 추가 확인이 필요한 것

같은 사용자가 평소·의도적으로 단조롭게·의도적으로 억양을 크게 말한 세션을 기준 등록과 분리해 비교해야 한다. 이후 여러 사용자·기기·녹음 환경에서 재현성과 잘못된 변화 빈도를 본다. 이번 10개를 재조합한 결과로 이런 실험을 대신하지 않는다. 옥타브 접힘은 큰 실제 억양도 축소할 수 있는 휴리스틱이다.
