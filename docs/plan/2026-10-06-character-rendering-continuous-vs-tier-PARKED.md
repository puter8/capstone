# [보류] 캐릭터 렌더링: 연속 vs 3단계 — PM 결정 대기

> **팀 확정 정책 · 2026-10-14:** 캐릭터 외형 변화는 **대화 세션 종료 후** 누적 결과로 공개한다. 대화 중 외형 유지가 의도된 UX이며 버그·재질문 대상이 아니다. **디자인 변경은 에너지 축 마감까지 보류**하고, 이후 검증된 신뢰도를 바탕으로 5축 매핑을 다시 결정한다. 아래 과거 구현·제안과 충돌하면 [캐릭터 표시 정책](../character-display-policy.md)을 우선한다.


> **상태: 보류(PARKED).** 5축 학습(Rubric v3.0 — ① Intimacy 완료, ② F/H/C 능동학습, ③ Energy) 작업이 끝난 뒤 다시 꺼내서 논의한다. 지금은 축 정확도 작업에 집중하고 이 주제는 건드리지 않는다.

## 배경

5축 매핑 참고 다이어그램을 Figma에 새로 만드는 과정에서(`05. 5축 매핑 가이드 (v3.0, 2026-10)`, https://www.figma.com/design/4kLxDLD2LdbB5BiY2QT5qU/?node-id=1187-803), "Intimacy처럼 모든 축을 연속적으로 연결된 느낌으로 바꿀 수 있나"는 질문이 나왔음. 이건 원래 진행하던 5축 학습 계획(Rubric v3.0)과 무관한 별도 주제라 분리해서 기록.

## 질문

지금 `PallyCanvas.tsx`는 Formality/Energy/Humor/Curiosity 4축을 0-33/34-66/67-100 **3단계 고정**으로 렌더링한다(PM 원 설계, 의도된 것 — 버그 아님). Intimacy만 색상 그라데이션으로 **연속** 렌더링된다. 전체를 Intimacy처럼 연속으로 바꾸면 사용자가 체감하는 변화가 더 와닿을지, 지금처럼 3단계로 뚜렷하게 나누는 게 더 와닿을지 — PM이 결정할 사항.

## 검토한 내용 (기술적 비대칭)

축마다 "연속화" 난이도가 다름:

| 축 | 연속화 난이도 | 이유 |
|---|---|---|
| Formality | 쉬움 | 모서리 radius가 숫자 하나 — 점수를 그대로 공식에 넣으면 바로 연속화됨 |
| Humor | 쉬움 | 움직임 폭도 숫자 하나 — 동일 |
| Energy | 어려움 | 사각형→8각 별→12각 별은 **아예 다른 도형**이라 중간 상태가 시각적으로 어색하게 깨질 위험 |
| Curiosity | 어려움 | 점→흰자+검은자→흰자+검은자+반짝임은 **요소 개수 자체가 변함**, 자연스러운 중간 상태 없음 |
| Intimacy | (이미 연속) | 색상 그라데이션이라 원래 연속에 적합한 표현 방식 |

## 제안 (하이브리드, 참고용 — 최종 결정 아님)

- Formality·Humor: 연속으로 전환 — 기술적으로 쉽고 자연스러움
- Energy·Curiosity: 3단계 유지 — 억지로 연속화하면 중간 단계가 어색해질 위험, 그리고 Achievements 같은 기능(예: "Energy 축 60 이상 기록하기")이 뚜렷한 상태 구분에 의존하고 있어서 전부 연속으로 바꾸면 "달성감"이 약해질 수 있음
