# 캐릭터 변화 검증 (2026-10-14)

> **팀 확정 정책 · 2026-10-14:** 캐릭터 외형 변화는 **대화 세션 종료 후** 누적 결과로 공개한다. 대화 중 외형 유지가 의도된 UX이며 버그·재질문 대상이 아니다. **디자인 변경은 에너지 축 마감까지 보류**하고, 이후 검증된 신뢰도를 바탕으로 5축 매핑을 다시 결정한다. 아래 과거 구현·제안과 충돌하면 [캐릭터 표시 정책](character-display-policy.md)을 우선한다.


결론: 채택한 모델의 점수와 캐릭터 설정은 변하지만, 3축 모두가 화면에서 충분히 드러나는 상태는 아니다. 유머의 시각적 반응은 현재 비활성이다. 모델 정확도와 화면 반응은 별도 문제다.

## 검증 범위

- 채택한 release_candidate 모델과 로컬 MiniLM 인코더로 새 예문 8개를 실제 추론했다. 실제 apply_ema 및 persona_prompt 함수를 실행했다. 사람 정답이 없는 기능 확인용 예문이므로 정확도 평가로 해석하지 않는다.
- 실제 Next.js `/dev/pally` 페이지를 headed Chromium, 360px viewport에서 열었다. 홈과 동일한 PallyCanvas에 슬라이더로 점수를 입력하고 동일한 애니메이션 시각의 Canvas RGBA 픽셀을 비교했다. Canvas 크기는 이 개발 페이지의 210px다.
- 각 축만 0/100으로 변경하고 나머지 축은 50으로 고정했다. 이는 렌더러의 반응을 분리하는 인위적인 경계 시험이다.
- 실제 음성 입력, Gemini 응답 생성, Supabase 저장, 운영 배포까지 연결한 E2E 검증은 하지 않았다. 유료 API 호출은 0회다.

## 모델 → 설정 및 표시 시점

- 실제 예문 점수 범위: 격식 20–70, 유머 0–10, 호기심 0–85. 이 작은 예문 집합의 낮은 유머 점수만으로 성능 실패를 판정하지 않는다.
- `yo dude whats up lol`: F20, H10, C0. 동일 발화를 기본 상태에서 3회 누적하면 F21, H10, C1.
- `Thank you for your consideration. I would appreciate your response.`: F70, H5, C5. 3회 누적하면 F69, H5, C5.
- `What do you think would happen if we changed the design?`: F70, H0, C85. 3회 누적하면 F69, H0, C83.
- 위 반복 시험은 각 예문마다 초기 상태를 재설정했다. 친밀도는 20으로 고정해 텍스트 축을 분리했으며, 실제 세션 수 계산을 재현한 것은 아니다.
- 실제 EMA 계수는 0.7이다. 새 점수 70%, 이전 값 30%를 반영한다. 일부 주석의 0.3 설명은 오래됐다.
- persona_prompt의 말투·유머·호기심 지시문은 해당 점수 구간에 따라 변한다. 실제 생성된 답변이 이를 따르는지는 이번 시험 범위 밖이다.
- 홈은 `updateFromChatResponse`에서 pendingAxes만 갱신한다. `completeConversation` 성공 후 `revealAxes`를 호출할 때 화면이 변한다. 따라서 매 발화 직후 외형이 변하지 않는 것은 현재 구현된 표시 정책이다.

## 구현 관찰 및 재매핑 참고 사항 — 디자인 변경 보류

1. 현재 유머의 시각 반응은 고정이다. 활성화 여부는 에너지 축 마감 후 신뢰도 기반 5축 재매핑에서 함께 결정한다. 지금 활성화하지 않는다.
2. 격식의 ±5% 모서리 보정은 시연에서 구별하기 어렵다. 변화 폭은 에너지 축 마감 후 재매핑에서 검토하며 지금 확대하지 않는다.
3. 호기심은 두 단계뿐이다. 단계·연속 표현 선택은 에너지 축 마감 후 재매핑까지 보류한다.
4. 개발 페이지의 독립 가중합 계산과 축별 시각 설명은 실제 백엔드·Canvas와 다르다. 이 페이지의 설명 수치를 검증 기준으로 쓰지 않았다.

이번 작업에서는 제품의 표시 정책이나 매핑을 바꾸지 않았다. 모델 채택과 별개로 디자인은 보류 상태이며, 에너지 축 마감 후 신뢰도 기반 5축 재매핑을 진행한다. 세션 종료 후 공개는 팀 확정 정책이고 수정 대상이 아니다.
