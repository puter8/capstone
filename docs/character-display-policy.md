# 캐릭터 표시 시점 및 디자인 보류 — 팀 확정 정책

확정 재확인: 2026-10-14, 사용자 전달 팀 결정. 과거 계획·검증 문서보다 이 정책을 우선한다.

## 표시 시점 — 확정, 재질문 불필요

- 대화 중에는 발화별 축 점수를 내부적으로 계산·누적한다.
- 축 점수에 따른 캐릭터 외형·색상·표정·움직임 특성 변화는 **대화 세션 종료 후** 누적 결과를 한 번에 공개한다.
- 사용자가 대화 전후의 변화를 더 뚜렷하게 체감하도록 팀에서 확정한 UX다. 발화 직후 외형이 변하지 않는 것을 버그·반영 지연·개선 과제로 분류하지 않는다.
- 사용자가 명시적으로 정책을 바꾸기 전에는 실시간 전환을 제안하거나 표시 시점을 다시 질문하지 않는다.
- 기본 애니메이션·깜빡임·처리 중 시선 등 상태 표현, 내부 점수 계산, 대화 응답 말투는 이 외형 공개 시점과 구분한다.
- 검증은 대화 중 외형 특성 유지 → 세션 종료 성공 → 누적 점수에 따른 외형 공개를 기준으로 한다. 현재 `usePally.ts`의 `pendingAxes` / `revealAxes()`가 이 정책을 구현한다.

## 디자인 — 에너지 축 마감까지 보류

- 에너지 축 작업이 아직 완료되지 않았다. 지금은 디자인과 축→시각 요소 매핑을 변경하지 않는다.
- 에너지 축 마감 후 **5축 각각의 검증된 신뢰도**를 바탕으로 전체 매핑을 다시 결정한다. 현재 매핑을 최종 디자인으로 확정하지 않는다.
- 유머 움직임 활성화, 격식 변화 폭 확대, 호기심 단계·연속 표현 변경은 즉시 실행할 수정이 아니라 이후 재매핑의 검토 자료다.
- 특정 축의 낮은 점수 분포 자체를 낮은 모델 신뢰도와 동일시하지 않는다. 사람 참조 점수 대비 성능과 검증 범위를 근거로 판단한다.
- 디자인 논의를 재개해도 세션 종료 후 공개 정책은 유지한다.

## 문서 해석

과거 보고서의 측정값과 당시 구현 기록은 보존한다. 실시간 외형 변화나 개별 축 디자인 변경 제안이 남은 과거 기록은 현재 실행 지시가 아니다. 모델 성능 검증과 디자인 보류는 별개이며 모델 연구·에너지 검증을 막지 않는다.
