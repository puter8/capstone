## 콘셉트 — 밤의 대화 노트

조용한 밤, 불 하나 켜진 방에서 친구와 이야기하고, 내가 한 말이 일기처럼 남는다.

1. **하나의 빛.** 팔리 뒤의 라일락 광원이 화면의 유일한 빛이다. 대화 상태는 캐릭터가 아니라 광원 세기와 고리로만 표현한다(말하는 중 고리 2개, 생각 중 점 3개). 일반 카드에는 그라데이션을 쓰지 않는다.
2. **세리프 = 영어 문장.** Fraunces는 대화 주제 제목, 팔리의 한 줄, 성향 단어, 영어 질문, 숫자에만 쓴다.
3. **교정은 칭찬처럼.** 라일락 굵게+밑줄 = 팔리가 고쳐 말한 표현(`correction`), 버터 굵게 = 새 표현(`new_expr`). 피드백 상세는 바뀐 단어를 흐린 취소선, 고친 표현을 버터 굵게+밑줄로 둔다. 오류색은 쓰지 않는다.
4. **조작은 한 곳에.** 하단 도크에 마이크(80px), 다시 듣기, 전체 대화를 모은다. 정지 아이콘은 녹음 중에만 쓴다.
5. **한 화면 한 주요 행동.** 보라 채움은 화면당 하나다.

## 데이터 근거 — 기본 시안과 제안의 경계

- **A. 지금 표시 중:** 팔리 답장 `pally_segments` 강조, `RecState`, 사용량, `FeedbackItem`, `streak_count`·`daily_tasks`, `display_name`·`traits`.
- **B. 데이터는 있지만 미표시(기본 시안에 넣음, 프론트 작업 필요):**
  - 홈 녹음 경과 시간과 30초 자동 정지 고리(`startedAt`, `useRecorder` 30초)
  - 팔리 응답 재생 건너뛰기(`stopPlayback` + `rec/speakingDone`). 지금은 응답 중 마이크가 비활성이고 재생을 멈출 길이 대화 종료뿐이다
  - 한도 다이얼로그 버튼 하나(`ConfirmDialog`는 지금 취소 버튼을 항상 그린다)
  - 녹음 중 "Listening..." 대신 점선 자리 표시
  - 팔리 답장 다시 듣기(`ConversationTurn.pally_audio_url`). 지난 메시지에서도 URL이 유지되는지 확인 필요
  - 기록 카드의 날짜 그룹·시간·대화 시간·`turn_count`·`feedback_count`·`preview`·그때의 팔리(`current_axes`)
  - 마이 페이지의 `english_level` 값, 요금제 상태 값, 내 팔리(`current_axes`) 렌더
  - 대화 상태에 따른 무대 광원·고리
  - 피드백 상세의 빨간 수정 표시를 흐린 취소선 + 버터 강조로 교체(`FeedbackCard`)
- **C. 데이터·기능 없음(06 섹션에만):** 녹음 파형, 번역 보기, 내 말 바로 교정(Loora식), 대화 요약, 주간 연속 기록, 연간 할인 표기.

신규 문구 제안(코드에 없는 문구)은 화면 아래 메모에 "신규 문구"로 표시했다. 예시는 홈 이름 인사, 피드백 탭 부제, 빈 기록 설명·버튼, 이름 단계 설명, 레벨 변경 영향 안내, 업적 부제다. 목소리 질문 번역문의 "· 영어로 답해요"는 제목과 중복돼 뺐다.

### 2차 재검증 (3개 관점) → 반영

새 에이전트 3개가 따로 검증했다. 관점은 해결 여부, 시각 퇴행, 접근성·문구다. 1차 16건 중 14건은 해결, 2건(13 용어, 16 카드 밀도)은 부분 해결로 판정됐다. 새로 나온 지적은 다음처럼 반영했다.

- **결함:**

### 구현용 접근성 지침 (컴포넌트 설명에 기록)

- **아이콘만 있는 버튼의 이름:**
  - 다시 듣기는 "Pally 말 다시 듣기", 전체 대화는 "전체 대화 보기", 뒤로는 "뒤로 가기"
  - 마이크는 상태별로 "말하기 시작" / "녹음 끝내기" / "Pally 말 건너뛰기" / "다시 말하기" / "답변 준비 중"
  - 사용량 칩은 "오늘 남은 대화 N회, 자세히 보기"와 `aria-expanded`
- **상태 알림:** 도크 상태 문구 하나만 `aria-live="polite"`로 두고, 상단 바 상태는 `aria-hidden`으로 둔다.
- **숨긴 컨트롤:** 시안에서 불투명도 0으로 자리만 지킨 컨트롤(응답 중 다시 듣기, 온보딩 첫 단계의 뒤로)은 `visibility:hidden` + `inert`로 구현한다.
- **기록 카드:** 제목 링크를 카드 전체로 넓히고(stretched link), "이어서 대화"는 형제 버튼으로 둔다. 상호작용 요소를 중첩하지 않는다.
- **교정 표시:** 새 표현은 점선, 고친 표현은 실선 밑줄로 형태를 구분한다. 화면에 보이지 않는 "고친 표현: …" 텍스트를 넣고, 피드백 원문은 `<del>`, 교정어는 `<ins>`로 표시한다.
- **언어 표시:** 영어 텍스트(말풍선, 주제 제목, 성향 칩, 질문)에는 `lang="en"`을 단다.
